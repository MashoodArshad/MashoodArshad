### Featured Projects

**[EmotiVoice — Speech Emotion Recognition](https://github.com/MashoodArshad/emotivoice)**
CNN-BiLSTM deep learning model that classifies emotion from raw speech audio across 8 classes, served through a FastAPI backend with real-time MFCC/mel-spectrogram feature extraction. Trained and evaluated on the RAVDESS dataset with a speaker-independent split to avoid data leakage.
`PyTorch` `FastAPI` `librosa` `pytest`

**[MedPredict AI — Client-Side Disease Risk Prediction](https://github.com/MashoodArshad/medpredict-ai)**
In-browser disease risk predictor for heart disease, diabetes, and breast cancer. Three models (logistic regression, random forest, linear SVM) are trained in scikit-learn, exported, and run entirely client-side in vanilla JavaScript — no backend, no data transmission.
`scikit-learn` `JavaScript` `Data Preprocessing`
